# Modelos de Clasificación de Texto

## 🔤 Clasificación con Sklearn y TF-IDF
- **Enfoque**: Uso de modelos tradicionales de ML con representación TF-IDF
- **Ventaja**: Rápida implementación y buen rendimiento en textos estructurados
- **Técnicas**: Preprocesamiento, vectorización y clasificación con Scikit-learn

## 📊 Naive Bayes y Pipelines
- **Algoritmo**: Naive Bayes para clasificación probabilística
- **Innovación**: Implementación de pipelines para flujos de trabajo reproducibles
- **Ventaja**: Eficiente con datasets grandes y fácil interpretación

## ⚡ Perceptron Simple desde Cero
- **Enfoque**: Implementación manual del perceptrón simple
- **Objetivo**: Comprensión fundamental de redes neuronales básicas
- **Aplicación**: Clasificación binaria con aprendizaje iterativo

## 🧠 Red Neuronal Multicapa PyTorch
- **Arquitectura**: Red neuronal profunda con múltiples capas
- **Framework**: Implementación usando PyTorch para flexibilidad
- **Ventaja**: Captura relaciones no lineales complejas en los datos

## 🔄 LSTM con Keras y Secuencias
- **Modelo**: LSTM (Long Short-Term Memory) para datos secuenciales
- **Enfoque**: Manejo de dependencias temporales en texto
- **Aplicación**: Ideal para análisis de sentimientos y clasificación de secuencias

## 🌐 Transformers Preentrenados con HuggingFace
- **Tecnología**: Uso de modelos transformers estado del arte
- **Ventaja**: Aprovechamiento de conocimiento preentrenado para tareas específicas
- **Flexibilidad**: Fine-tuning eficiente para múltiples dominios textuales

## 📚 Uso Recomendado
- **Sklearn + TF-IDF**: Prototipado rápido y baseline de rendimiento
- **Naive Bayes + Pipelines**: Procesos automatizados y modelos interpretables
- **Perceptron Manual**: Aprendizaje educativo de fundamentos de ML
- **Red Neuronal PyTorch**: Modelos personalizables y experimentación avanzada
- **LSTM con Keras**: Problemas con dependencias temporales y secuenciales
- **Transformers HuggingFace**: Estado del arte en tareas de NLP complejas
