# Transfer Learning en NLP

## 🧠 Clasificador de Sentimientos con Perceptrón Simple
- **Arquitectura**: Modelo lineal básico para análisis de sentimientos
- **Enfoque**: Implementación manual de perceptrón para clasificación binaria
- **Ventaja**: Simplicidad y velocidad de entrenamiento

## 🧠 Clasificación de Sentimientos con Red Neuronal Multicapa
- **Arquitectura**: Red neuronal profunda con múltiples capas ocultas
- **Capacidad**: Captura de relaciones no lineales complejas en texto
- **Aplicación**: Mejoramiento sobre modelos lineales para sentimientos

## 🔄 Análisis de Sentimiento con Red LSTM usando Keras
- **Modelo**: LSTM para capturar dependencias temporales en secuencias
- **Ventaja**: Manejo efectivo de contexto y orden en texto
- **Framework**: Implementación con Keras/TensorFlow

## 🌐 Análisis de Sentimiento con Modelos Preentrenados
- **Técnica**: Transfer learning con embeddings y modelos preentrenados
- **Enfoque**: Aprovechamiento de conocimiento de grandes corpus
- **Eficiencia**: Menor tiempo de entrenamiento y mejor rendimiento

## 💻 Laboratorio Práctico
- **Objetivo**: Aplicación integral de técnicas de transfer learning
- **Enfoque**: Implementación end-to-end de pipelines de NLP
- **Metodología**: Comparación entre diferentes aproximaciones

## 📚 Ejercicios
- **Propósito**: Refuerzo práctico de conceptos teóricos
- **Variedad**: Desde implementaciones básicas hasta avanzadas
- **Aplicación**: Desarrollo de habilidades en transfer learning

## 📊 Uso Recomendado
- **Perceptrón Simple**: Baseline y comprensión de fundamentos
- **Red Neuronal Multicapa**: Mejora de capacidades de modelado
- **LSTM con Keras**: Problemas con dependencias secuenciales largas
- **Modelos Preentrenados**: Máximo rendimiento con fine-tuning
- **Laboratorio**: Integración de conocimientos y aplicación práctica
- **Ejercicios**: Consolidación de aprendizaje y desarrollo de habilidades
